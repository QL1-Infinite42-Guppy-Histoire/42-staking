42 ステーキング

42 Chain のバリデーターに 42 を預け入れてステーキングすると、報酬（利回り）がもらえるサイトです。流動性ステーキング（st42）とは違う、バリデーターへ直接預けるステーキングです。署名は MetaMask などの EVM ウォレットで行います。

全ての製品はオープンソース（MITライセンス）です

預け入れて、利回りを得る

42 をバリデーターに預け入れると、ネットワークから報酬（利回り）がもらえます。

預けた 42 がネットワークの安全を支え、その対価として報酬が増えていきます。報酬率は固定ではなく、ネットワークの状況で変動します。

対応ウォレットが見つかりません

このサイトは EVM ウォレット全般（MetaMask、FoxWallet の EVM モード、GuppyWallet 拡張機能など）で使います。PC ではウォレット拡張機能を入れてから開くか、スマホではウォレットアプリ内のブラウザで開いてください。

詳細

ステーキング・プリコンパイル: 0x0000000000000000000000000000000000000800（validators / delegation / unbondingDelegation / delegate / undelegate / redelegate）。 配布プリコンパイル: 0x0000000000000000000000000000000000000801（delegationTotalRewards / delegationRewards / validatorCommission / withdrawDelegatorRewards / withdrawValidatorCommission）。 このチェーンにはステーキング一覧の取得メソッドがないため、サイトは全バリデーターに1件ずつ確認しています（25件）。 「報酬を全部受け取る」はバリデーターごとに1件ずつ取引を送ります。解除には21日かかります。 チェーン: 42 Chain（EVMチェーンID 421018、Cosmos ID infinite_421018-1）、ネイティブトークン 42（基本単位 “drop”、18桁）。
